## Fallback (6.16)

- The 6.16 flash flow writes only `boot_a` (96 MiB, 100663296 bytes):
  `tools/dodge-chain pack`, then `tools/dodge-chain footer` adds the AVB hash
  footer (partition `boot`, SHA256_RSA4096, padded to the partition size).
- Read back on the phone (6.16.0-gbd9587d65), read-only:
  `dd if=$(readlink -f /dev/disk/by-partlabel/boot_a) bs=1M | sha256sum` gave
  `9940497e7870b8b6b5ef1d28166801dbdbcf4f22a8e24f32e468f11a6b044af4`. That
  equals the host `out-dodge-chain-cfg1/images/boot-chain-avb.img` (the
  2026-10-21 config-bump flash).
- Kept as `~/android/mainline/images/FALLBACK-6.16-boot_a-9940497e.img`.
- Restore (phone in fastboot): `tools/dodge-restore-616`, which checks the
  sha256 and size, then runs
  `fastboot flash boot_a <fallback> && fastboot set_active a && fastboot reboot`.
  One-shot without writing: `tools/dodge-restore-616 once`
  (`fastboot boot <fallback>`).

## Deadline logic: trial vs flashed default

Before this, the 80 s check never cancelled on any 7.x kernel, so a flashed
7.3 would have rebooted every 220 s (`/root/dodge-deadline` stays on the
phone, so every boot arms).

Now the key is the cmdline, not the kernel version:
- trial = a 7.x kernel without `dodge.flashed` in `/proc/cmdline`. Every
  older or one-shot trial image lacks it, so they stay in trial mode
  (fail-safe): 220 s, never cancelled by a clean display, soak flag honoured.
- flashed default (7.3 with `dodge.flashed`) behaves like 6.16: armed
  (220 s of 7.x uptime, about 240 s from power-on), cancelled at 80 s only if
  there is no DSI tx failure / panel init failure / frame-done or kickoff
  timeout and DSI dpms is On. A stale soak flag is removed, not used.
- 6.16 is unchanged. The dpms read now globs `card*-DSI-1`.
- The arm line logs `trial=0|1`.

Checked by hand with stubbed `uname`/cmdline (6.16 and 7.3, with and without
the word) and then on the phone: a one-shot `fastboot boot` of the unfootered
flash image (16:06 CEST) logged `armed --on-boot=220 s ... trial=0` and at
80.9 s `clean (dpms On), reboot cancelled`; no timers left. Gated reboot back
to 6.16 at 16:09.
