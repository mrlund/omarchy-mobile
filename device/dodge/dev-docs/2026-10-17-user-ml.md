# 2026-10-17 — user ml, password locked

**Goal.** Add the desktop account before Hyprland. No display start,
no flash.
**Phone.** OnePlus 13 CPH2653. Omarchy 4.0.4 on `/dev/sda15`.
**Kernel.** `6.16.0-gb3ee311dab85`
**Result.** Pass. `ml` (uid 1000) logs in over SSH. `sudo` has no
password to accept.

## What we did

`useradd -m -G wheel,audio,video,input -s /bin/bash ml`, then
`passwd -l ml`. The laptop's key was copied to
`/home/ml/.ssh/authorized_keys` (mode 600, owner ml). `%wheel` was
already in sudoers, so no sudoers file was added. Hyprland was not
started. The default target is still multi-user.

## What happened

`ssh ml@172.16.42.1` returns uid 1000 and the four groups. `sudo -n`
asks for a password, and the account is locked, so there is nothing
to type. Root SSH still administers the phone. Hyprland 0.56.2 is
installed. `/dev/dri/card0` is the simpledrm device, group `video`.

## Learning

The session user can open the DRM device. Starting Hyprland replaces
the console and has to be watched for the aquamarine retry loop in
the desk check. A password for `ml`, if one is wanted, has to be
chosen by the human. The phone clock is still in September, so file
times on the root look early.
