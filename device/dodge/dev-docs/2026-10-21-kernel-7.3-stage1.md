# 2026-10-21: Linux 7.3 stage 1 (display, touch, USB) as a one-shot stage 2

The branch is `trial/omamobile-dodge-port` (local), backed up in
[../kernel-7.3/](../kernel-7.3/). Release `7.3.0-rc6-dodge-s1`. Times are CEST.
Every boot is `fastboot boot` of `out-dodge-chain-73/images/boot-chain.img`;
the 6.16 stage 1 is unchanged, and boot_a is never flashed.

## Kernel

- The ports and fixes are listed in `../kernel-7.3/README.md`. ATH12K is off
  (patch 0004 needs the MHI TME port, which is stage 4).
- The two DSI rounding patches (0047/0048) were dropped; their net diff on 7.3
  was empty.
- New on 7.3: `GUNYAH_WATCHDOG=y`. qcom_scm registers it when the DT has no
  watchdog node.

## Rootfs (safe on 6.16)

- `kernel/omamobile-kmod-overlay`: binds `/usr/lib/modules/<R>.held` and
  `/usr/local/lib/omamobile.<R>` over the pinned loader paths. It is now
  idempotent and reads `skip-units`, creating `/run/omamobile-skip/<unit>`
  for each listed unit. `kernel/50-omamobile-kernel-skip.conf` is a drop-in on
  12 units with `ConditionPathExists=!/run/omamobile-skip/%n`. On 6.16
  nothing is skipped (checked: ConditionResult=yes).
- `kernel/30-omamobile-watchdog.conf`: `RuntimeWatchdogSec=20s`. On 6.16
  there is no `/dev/watchdog`, so it has no effect there. On 7.3 the
  initramfs feeds the watchdog until switch_root kills the feeder, then
  systemd opens it (Gunyah max is 32 s).
- `display/omamobile-display-msm`: loads the `modules.dep` deps of each
  module first, and skips built-ins. On 6.16 every dep is already in the
  list (checked against the running boot), so nothing changes.
- The 7.3 stage 1 skip list covers battery/ADSP, BT, audio, sensors, Wi-Fi
  (both) and modem (4 units). So there is **no battery reading on 7.3**, and
  the reboot back has no gate. Each 7.3 boot is gated on 6.16 just before.
