# 2026-10-17 — peach DMA kept in the low 256 MiB

**Goal.** Put the firmware memory segments inside stock's low
window and see if TME-Lite error 83 changes.
**Phone.** OnePlus 13 CPH2653. No restart. Desktop stayed up.
**Kernel.** `6.16.0-gb3ee311dab85`, module from `ee9e6c363`.
**Result.** Fail. The segments landed in the low 256 MiB and
the firmware reached TME-Lite again. The answer is still
`result 1, err 83`. No `wlan`.

## What the phone did

`pci dma mask 28 bits`. The firmware asked for the same three
segments, at low addresses:

```
qmi mem seg[0] type 1 size 7405568 addr 0x000000000e800000
qmi mem seg[1] type 4 size 4145152 addr 0x000000000e400000
qmi mem seg[2] type 11 size 4096 addr 0x000000000e3ff000
```

Target capabilities and the peach build string followed.
TME-Lite then failed, the firmware reset about 200 ms later,
and mode 7 timed out. Hyprland stayed active. oops count 0.
ath12k is bound. Do not load it again on this boot.

## Learning

Moving the buffers out of the top of the 32-bit space does
not change error 83. The 36-bit aperture advertisement did,
by resetting the firmware earlier. This mask does not.
