# 2026-10-24: 7.3 Wi-Fi and Bluetooth boot tests

One-shot `fastboot boot` of `boot-chain-wifibt-20261024.img` (kernel HEAD
5a702eac6, 7.3.0-rc6-dodge-s1). Nothing flashed. Battery gate passed before
each boot (100 %). Back on 6.16 with the display connected/On after each one.

## Phone prep (7.3 trees only; 6.16 trees untouched)

- `/usr/lib/modules/7.3.0-rc6-dodge-s1.held` replaced with a fresh
  `modules_install INSTALL_MOD_STRIP=1` (old one kept as `.held.pre-wifibt`).
- `/usr/local/lib/omamobile.7.3.0-rc6-dodge-s1`: every `.ko` refreshed with
  `tools/dodge-kmod-overlay-tree`, plus `ath12k.ko`, `ath12k_wifi7.ko` and
  `bt/kpp.ko` (old dir kept as `omamobile.7.3.0-rc6-dodge-s1.pre-wifibt`).
- `skip-units`: Wi-Fi (pcie, ath12k) and BT units no longer skipped on 7.3.
  Modem, rmtfs, tqftpserv, mm-netport and sensors stay skipped.
- Firmware: `ath12k/WCN7860/hw2.0/aux_ucode.bin -> aux_ucode20.elf`, a new
  symlink. 7.3 loads `aux_ucode.bin`. No stock file was changed.
- `wifi/omamobile-wifi-ath12k` now also inserts `ath12k_wifi7.ko` when it
  exists. 7.3 splits out the PCI driver; 6.16 has no such file.
- `bluetooth/omamobile-bt` now loads `kpp.ko` first when it exists. kpp is a
  module on 7.3 and built in on 6.16.

## Wi-Fi: where it stops

- PCIe link is up and ath12k_wifi7_pci binds 17cb:110e as "wcn7860 hw2.0".
- MHI power-on, then BHI of the 512 KiB SBL waits the full 90 s and returns
  -EIO with pm_state = LD_ERR_FATAL_DETECT.
- The register dump on wifibt2 shows BHI_EXECENV = 1 (SBL) and BHI_STATUS
  bits 31:30 = success. So the device accepted the SBL; the host was never
  woken.
- `mhi_fw_load_bhi`, `ath12k_pci_power_up`, `ath12k_pci_sw_reset` and the
  ath12k MHI setup are the same on 6.16 and 7.3, apart from the config
  tables, which moved to wifi7/. On 6.16 the same step takes under 50 ms.
- Leading hypothesis: the MHI MSI is not delivered on 7.3. Next step is to
  compare `/proc/interrupts` and the PCIe MSI path.
- QMI is never reached, so the qrtr_node_id lead (0x1e03300 vs 0x1E03164)
  is not what stops this boot. That register is also only written with
  FW_FEATURE_MULTI_QRTR_ID.

The full facts are in the host log `2026-10-24-p73-wifi-bhi-facts.md` (not
committed).
