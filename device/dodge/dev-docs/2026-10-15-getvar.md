# 2026-10-15 — fastboot getvar, still locked

**Goal.** Read the boot chain: product, slot, bootloader version, and
the GPT names. Do not unlock.
**Phone.** CPH2653, build `CPH2653_16.0.10.501(EX01)`. Cable attached.
**Kernel.** No kernel of ours. OxygenOS was running, then the
bootloader menu.
**Result.** Pass for the read. The phone is still locked. Unlock was
not sent.

## What we did

The phone first enumerated as the OxygenOS USB tether (`22d9:276a`,
RNDIS only). After USB debugging and file transfer it was `22d9:2765`,
with an adb interface (`ff/42/01`). `adb devices -l` reported product
`CPH2653EEA`, model `CPH2653`, device `OP5D55L1`. That matches the OTA.

`adb reboot bootloader` left OxygenOS. The screen showed the bootloader
menu (Start, reboot, recovery). `fastboot getvar all` was saved at
`~/android/reference/dodge-cph2653/fastboot-2026-10-15/getvar-all.txt`.
That file stays out of git. It contains the serial.

## What happened

`is-userspace:no` and `kernel:uefi`, so this is ABL's fastboot, not
fastbootd. `product:sun`. `unlocked:no`. `secure:yes`.
`current-slot:a`. `slot-count:2`.

| Slot | successful | unbootable | retry-count |
| --- | --- | --- | --- |
| a | yes | no | 6 |
| b | yes | yes | 6 |

`version-bootloader` and `version-baseband` are empty. The OTA metadata
has no bootloader version either, so the "matches the OTA" check cannot
be made from these two sources. `hw-revision` is `20000`. `variant` is
`SM8 UFS`. `max-download-size` is 805306368.

`recovery_a` and `recovery_b` are real partitions, each `0x6400000`
(100 MiB), the same size as the OTA's `recovery.img`. There is no
`vendor_kernel_boot`. Boot-image sizes: `boot` `0x6000000`, `init_boot`
`0x800000`, `vendor_boot` `0x6000000`, `dtbo` `0x1800000`, `vbmeta`
`0x10000`, each on both slots. `userdata` is f2fs.

Fastboot's variable list named no `modemst1`, `modemst2`, `fsg`, `fsc`
or `efs`. `persist` is present, and was not read. `modem_a` and
`modem_b` are present. The GPT probed on 2026-10-16 does name
`modemst1`, `modemst2`, `fsg` and `fsc` (on `sdf`). There is still no
`efs`
([2026-10-16-ufs-probe.md](2026-10-16-ufs-probe.md)).

## Learning

This is the right phone: adb's product string is the OTA's, and
fastboot's `product:sun` is the SoC name. Slot B is marked unbootable,
so it is not a fallback and `set_active` stays forbidden (§3.3). The
bootloader version of each slot is still unknown. Unlock is the next
step and erases userdata. It was not sent. The menu was left up.
