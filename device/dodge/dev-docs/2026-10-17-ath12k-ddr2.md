# 2026-10-17 — stock-sized host DMA window

**Goal.** Advertise stock's combined IOMMU window in host cap,
with the firmware segments inside it.
**Phone.** OnePlus 13 CPH2653. One restart. Desktop stayed up.
**Kernel.** `6.16.0-gb3ee311dab85`
**Result.** Fail. The firmware reset before it acknowledged
the memory response. No TME-Lite request. No `wlan`.

## What the phone did

Host cap logged `ddr range 0x0 size 0x68000000`. That is
stock's `0x18000000` window plus its `0x50000000` window.
The 28-bit DMA mask was still on, and the segments were
inside that range:

```
qmi mem seg[0] type 1 size 7405568 addr 0x000000000e800000
qmi mem seg[1] type 4 size 4145152 addr 0x000000000e400000
qmi mem seg[2] type 11 size 4096 addr 0x000000000f07d000
```

About 150 ms later: `ignore reset dev flags 0x12`, then
`qmi failed memory request, err = -110`. Hyprland stayed
active. oops count 0. ath12k is bound. Do not load it again
on this boot.

The on-disk module does not send `ddr_range`. Leaving the
field unset is what still reaches TME-Lite, which returns
`err 83`.
