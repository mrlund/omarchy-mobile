# 2026-10-15 — first dodge loop image, packed and not booted

**Goal.** Write `tools/dodge-try` and the first initramfs, and pack a
self-contained header v2 image on the laptop.
**Phone.** Not touched. CPH2653, build `CPH2653_16.0.10.501(EX01)`.
**Kernel.** Built, not booted. `6.16.0-g16cf517b2781`, from
`sm8750-mainline` `v6.16` at `16cf517b2781`.
**Result.** Pass for the pack. The image has not been handed to fastboot.

## What we did

`kernel/configs/omamobile-dodge.config` is merged onto arm64 defconfig
by `tools/dodge-try config`. The loop drivers are built in, because the
ramdisk carries no modules. `tools/dodge-try pack` then builds `Image`,
`qcom/sm8750-oneplus-dodge.dtb`, an Alpine initramfs and
`~/android/mainline/out-dodge/images/boot.img`. `pack` does not call
fastboot or adb. `boot` is the subcommand that would, and it was not run.

The init is `device/dodge/initramfs/init`. It follows cheetah's
first-light init with the gs201 parts removed: no `devmem`, no DECON
trigger write, no DPP or watchdog register reads. It also does not copy
cheetah's slot-B allowlist or its `switch_root`. Every SCSI disk is set
read-only, and PID 1 stays in the ramdisk. The USB gadget is still
`1d6b:0104` (Linux Foundation multifunction, NCM + ACM), address
`172.16.42.1/24`, dropbear key login only. If the host never configures
the gadget, init writes sysrq `c` so `panic=10` reboots into OxygenOS.

The watchdog feeder opens `/dev/watchdog0` only if the node appears. On
this DTB it does not. The feeder then writes one line to kmsg and exits.
That is not a reset path ([../PLAN.md](../PLAN.md) §5.1).

Alpine is the same minirootfs `bin/omamobile` pins,
`alpine-minirootfs-3.24.2-aarch64.tar.gz`, plus the `dropbear` package.
This busybox has `udhcpc` and not `udhcpd`. The laptop profile
`omamobile-phone` is static `172.16.42.2/24`, so the image does not run
a DHCP server. `setsid`, `tee` and `head` are busybox symlinks under
`/usr/bin`. On the laptop those links look dangling, because they point
at `/bin/busybox` inside the ramdisk.

The image command line is
`clk_ignore_unused pd_ignore_unused panic=10 console=tty0`.
`console=tty0` is the panel, if simpledrm binds a framebuffer the
bootloader left behind. Stock's `console=ttynull` and `nosoftlockup`
are not on this image.

`FB_SIMPLE` in this tree depends on `!DRM_SIMPLEDRM`, so the fragment
selects `DRM_SIMPLEDRM` and not `FB_SIMPLE`. `SCSI_UFS_QCOM` stayed `=m`.

## What happened

The first `pack` stopped in `Kbuild` because `bc` was not installed
(`timeconst.h`, exit 127). After `bc` 1.08.2 was installed, the Image
built. A check for `udhcpd` then failed; that applet is not in this
minirootfs. The next check looked for `setsid` only in `/bin` and
failed the same way: the link is `/usr/bin/setsid`.

The pack that completed wrote:

| | |
| --- | --- |
| Image | 40376832 bytes, `6.16.0-g16cf517b2781` |
| DTB | 87477 bytes, the 0c dodge DTB, no `qcom,msm-id` or `qcom,board-id` |
| ramdisk | 5007757 bytes, lz4 legacy |
| boot.img | 45481984 bytes, header version 2 |

`unpack_bootimg` reports kernel `0x8000`, ramdisk `0x01000000`, tags
`0x100`, dtb `0x01f00000`, page size 4096. Those are the stock
`vendor_boot` offsets from §6, with `--base 0`. The image sha256 is
`2c1914fa4ebc7dfb1f9169dde9249f4db3f33fef2bdfac95c321f1a951c09f25`.
The image stays under `~/android/mainline/out-dodge/` and out of git.

Built-in after `olddefconfig`: `USB_CONFIGFS`, `USB_DWC3_QCOM`,
`PHY_QCOM_QMP_COMBO`, `PHY_QCOM_M31_EUSB`, `PHY_QCOM_EUSB2_REPEATER`,
`DRM_SIMPLEDRM`, `PSTORE_RAM`, `QCOM_WDT`, `PANIC_TIMEOUT=10`,
`BOOTPARAM_SOFTLOCKUP_PANIC`, `BOOTPARAM_HUNG_TASK_PANIC`.
`SCSI_UFS_QCOM=m`.

No fastboot or adb command was run.

## Learning

The host list needs `bc`. The image's DTB is still the one ABL will not
match on board-id; which of the eight sun/sunp pairs to copy stays open
until a live FDT (§5.3 step 2). `tools/dodge-try boot` is a phone step.
Its OxygenOS deadline is 600 s and has not been measured; phase 1 times
a cold boot and replaces that number. A hang that does not panic still
waits for a human.
